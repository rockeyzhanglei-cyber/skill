# 规则A：区域卫生信息平台数据传输规范

**适用条件**：当检测到列头包含"数据元标识"、"数据元名称"、"约束"、"表示格式"时，使用此规则。

## 列头含义映射

| 列头名称 | 含义 | 解析处理 |
|---------|------|---------|
| 数据元名称 | 字段中文名称 | 用于修订记录中的字段名中文和DDL注释 |
| 数据元标识 | 字段英文名称 | 用于DDL中的实际字段名 |
| 数据类型 | 数据类型表示符 | S1/S2/S3→VARCHAR，N→NUMBER/NUMERIC，DT→DATE，D→DATE，详见类型映射 |
| 约束 | 是否必填 | M=强制→NOT NULL，C=条件可选→NULL，O=可选→NULL |
| 表示格式 | 字段长度/精度 | 如 `AN..64` → VARCHAR(64)，`N..10` → NUMBER(10) |
| 说明 / 定义 | 备注信息 | 用于DDL字段注释和主键检测（复合主键） |

## 约束定义

| 约束值 | 含义 | 说明 | SQL约束 |
|-------|------|------|---------|
| M | 强制（Mandatory） | 强制要求该数据元应填充信息，如果没有值，数据将不能被合法解析 | NOT NULL |
| C | 条件可选（Conditional） | 符合特定条件时必须填充信息 | NULL（可选） |
| O | 可选（Optional） | 无论信息是否存在，可选择填充或不填充 | NULL |

## 数据类型定义

| 数据类型 | 表示符 | 描述 | DDL类型映射 |
|---------|-------|------|------------|
| 字符型（string） | S1 | 字符形式表示的值的类型，不可枚举 | VARCHAR |
| 字符型（string） | S2 | 字符形式表示的值的类型，枚举型 | VARCHAR |
| 字符型（string） | S3 | 字符形式表示的值的类型，代码表 | VARCHAR |
| 数值型（number） | N | 数字字符形式表示的值的类型 | NUMBER/DECIMAL |
| 数字字符型 | N1/N2/Nn | 固定长度数字字符（只允许数字，但类型是VARCHAR） | VARCHAR(n) |
| 布尔型（boolean） | L | 逻辑型，采用F(False)或T(True)形式表示 | VARCHAR(1) 或 NUMBER(1) |
| 日期型（date） | D | 格式为YYYYMMDD | DATE |
| 时间型（time） | T | 格式为HHMMSS | VARCHAR(6) 或 TIME |
| 日期时间型（datetime） | DT | 格式为YYYY-MM-DD HH24:MI:SS | DATE（Oracle） |
| 二进制（binary） | BY | 其他数据类型，如二进制流文件格式 | BLOB |

**重要说明**：
- **S1/S2/S3** 都是字符型，统一映射为 VARCHAR
- **N1/N2/Nn** 是固定长度的数字字符型，虽然只允许数字，但字段类型仍是 VARCHAR(n)
- 只有单独的 **N** 类型类别（无固定长度）才映射为 NUMBER/DECIMAL

## 表示格式类别定义

| 类别 | 含义 | 示例 |
|------|------|------|
| A | 字母字符，默认UTF-8编码收录字符 | A..18 |
| N | 数字字符，0~9 | N4 |
| AN | 字母和（或）数字字符 | AN..64 |
| D10 | 日期，采用YYYY-MM-DD格式 | D10 |
| T8 | 时间，采用hh:mm:ss格式 | T8 |
| DT19 | 日期时间，采用YYYY-MM-DD HH24:MI:SS格式 | DT19 |

## 表示方法定义

| 表示方法 | 格式说明 | 解析示例 |
|---------|---------|---------|
| 固定长度 | 表示符后直接给出字符长度数目 | `N4` → NUMBER(4)，`AN8` → VARCHAR(8) |
| 可变长度（最大） | 字符可变长度不超过最大数目，用`..`分隔 | `A..18` → VARCHAR(18)，`AN..64` → VARCHAR(64) |
| 可变长度（范围） | 字符可变长度在最小和最大数目之间 | `AN4..18` → VARCHAR(18) |
| 多行字符 | 在长度定义后加"X"再定义最大行数 | `AN4..18X3` → CLOB/TEXT |
| 有小数位 | 在长度后加","再定义小数位数 | `N5,2` → NUMBER(5,2) |
| **不限长度** | 表示符+..*，无长度上限 | `AN..*` → CLOB/TEXT |

## 哪些格式不应出现在规范文档中（请用户修正文档）

以下格式不符合上述规范，**不自行容错推算默认长度**，而是列出给用户修改文档：

| 文档中见到的格式 | 问题说明 | 正确写法 |
|-----------------|---------|---------|
| `4000`, `64`, `18` 等裸数字 | 缺少AN..前缀，无法确定语义 | 应加前缀如 `AN..4000` |
| `M1` 等非标准前缀 | 文档笔误，M不是标准表示符 | 标准前缀：A/AN/N/DT/D/T/S |
| `AN..`（无数字） | 缺少最大长度值 | 应写具体长度如 `AN..50` |
| `AN..AN..50` | 重复前缀 | 应改为 `AN..50` |
| `N..6，2` 中文逗号 | 逗号用了全角 | 应为英文逗号 `N..6,2` |
| `AN．64` 全角点 | 点用了全角U+FF0E | 应为 `AN..64`（这个可以自动修复） |

**容错规则**：仅全角点(U+FF0E→U+002E)和不可见字符(零宽空格等)可自动修复，因为这些是文档编辑时引入的字面量变形。

| 数据元标识 | 数据元名称 | 约束 | 数据类型 | 表示格式 | 说明 |
