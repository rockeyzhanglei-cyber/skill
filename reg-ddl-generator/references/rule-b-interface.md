# 规则B：数据采集接口标准

**适用条件**：当检测到列头包含"字段"、"字段名"、"类型"、"长度"、"填报要求"时，使用此规则。

## 典型列头格式

```
| 字段 | 字段名 | 类型 | 长度 | 填报要求 | 说明 |
```

## 列头含义映射

| 列头名称 | 含义 | 解析处理 |
|---------|------|---------|
| 字段 | 字段中文名称 | 用于修订记录中的字段名中文和DDL注释 |
| 字段名 | 字段英文名称 | 用于DDL中的实际字段名 |
| 类型 | 数据类型 | VARCHAR、NUMERIC、INT、T/F、D、T、DATETIME、二进制 |
| 长度 | 字段长度/精度 | 数字直接填写，如 `22`、`64`；NUMERIC用`(N,M)`格式 |
| 填报要求 | 是否必填 | **必填**→NOT NULL，**应填**→NULL |
| 说明 | 备注信息 | 用于DDL字段注释 |

## 填报要求定义

| 填报要求值 | 含义 | SQL约束 |
|-----------|------|---------|
| 必填 | 必须要填报的字段 | NOT NULL |
| 应填 | 如果业务系统中有相应数据则必须填报，没有则可以不填报 | NULL（可选） |

## 数据类型定义

| 数据类型 | 表示符 | 描述 | DDL类型映射 |
|---------|-------|------|------------|
| 字符型 | VARCHAR | 通过字符形式表达的值的类型，可包含字母、数字等 | VARCHAR |
| 数字型 | NUMERIC | 长度表示符(N,M)，N为最长长度含小数点，M为小数位数 | NUMERIC/DECIMAL |
| 整型 | INT | 整数 | INT/INTEGER |
| 布尔型 | T/F | 逻辑型，采用F(False)或T(True)形式表示 | VARCHAR(1) 或 NUMBER(1) |
| 日期型 | D | 格式为YYYYMMDD | DATE |
| 时间型 | T | 格式为HHMMSS | VARCHAR(6) 或 TIME |
| 日期时间型 | DATETIME | 格式为YYYYMMDD HHMMSS | DATETIME/TIMESTAMP |
| 二进制型 | 二进制 | 图象、音频、视频等二进制流文件 | BLOB |

## 系统字段（接口必填）

所有数据采集接口表都必须包含以下系统字段：

| 字段 | 字段名 | 类型 | 长度 | 填报要求 | 说明 |
|------|-------|------|------|---------|------|
| 医疗机构代码 | YLJGDM | VARCHAR | 22 | 必填 | 填写医疗机构组织机构代码 |
| 密级 | MJ | VARCHAR | 16 | 必填 | 由16位编码组成，用于病种权限控制和特控调阅 |
| 填报日期 | TBRQ | DATETIME | - | 必填 | 机构向数据中心填报数据当天的日期时间 |
| 修改标志 | XGBZ | VARCHAR | 1 | 必填 | 1：正常、2：修改、3：撤销 |

## 长度格式解析

| 类型 | 长度格式 | DDL示例 |
|------|---------|---------|
| VARCHAR | 数字直接填写 | `VARCHAR(22)`、`VARCHAR(64)` |
| NUMERIC | `(N,M)`格式，N含整数+小数点+小数位 | `NUMERIC(10,2)` 表示最长10位含2位小数 |
| INT | 无长度或直接数字 | `INT` 或 `INTEGER` |
| DATETIME | 无长度 | `DATETIME` 或 `TIMESTAMP` |

## 多选字段说明

- 多个选项之间，存储代码的字段以"`/`"（左斜杠）分隔
- 存储名称的字段以"`;`"（英文分号）分隔
