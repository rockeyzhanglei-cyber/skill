# table_structure.md 固定模板

> 本文件定义了 Word 文档解析后生成的 MD 文件格式。
> 所有下游脚本（生成导出SQL、对比修复）都依赖此格式，**不可随意变更**。

## 文件结构

```
# 数据库表结构定义

## 数据来源
- 文档名称：{文档名称}
- 解析时间：{YYYY-MM-DD}
- 表总数：{N}

## 表清单

| 序号 | 中文名 | 英文表名 | 是否有TRAN | 是否有LOG |
|------|--------|----------|------------|-----------|
| 1    | xxx    | XXX_XX   | 是/否      | 是/否     |
| ...  | ...    | ...      | ...        | ...       |

---

## 表{N}：{英文表名}（{中文名}）

### 字段定义

| 序号 | 数据元标识 | 数据元名称 | 约束 | 数据类型 | 表示格式 | 说明 |
|------|------------|------------|------|----------|----------|------|
| 1    | YLJGDM     | 医疗机构代码 | M  | S1       | AN..64   | ...  |
| ...  | ...        | ...        | ...  | ...      | ...      | ...  |

---
```

## 字段说明

### 表清单章节

| 列名 | 说明 | 示例 |
|------|------|------|
| 序号 | 从1递增的序号 | 1, 2, 3... |
| 中文名 | 表的中文名称 | 医护人员信息表 |
| 英文表名 | 表的英文名称（大写） | JBYHRYXXB |
| 是否有TRAN | 文档中是否定义了同名_TRAN表 | 是/否 |
| 是否有LOG | 文档中是否定义了同名_LOG表 | 是/否 |

### 字段定义章节

| 列名 | 说明 | 取值范围 |
|------|------|----------|
| 序号 | 从1递增的字段序号 | 1, 2, 3... |
| 数据元标识 | 字段英文名（大写） | YLJGDM |
| 数据元名称 | 字段中文名 | 医疗机构代码 |
| 约束 | 必填性约束 | M / O / C |
| 数据类型 | 文档定义的数据类型 | S1 / S2 / S3 / S / N / D / DT |
| 表示格式 | 长度/精度格式 | AN..64 / N{10,2} / N1 / D10 / DT19 / AN..* |
| 说明 | 字段说明/枚举值 | 复合主键... |

## 解析规则

1. **表名标题格式**：`## 表{N}：{英文表名}（{中文名}）`
   - 必须使用全角冒号`：`或半角冒号`:`均可
   - 中文名必须用括号（全角或半角均可）包裹
   
2. **字段定义表格**：
   - 必须包含表头行和分隔行
   - 列数固定为7列
   - 空值用`-`或空字符串填充

3. **表间分隔**：每个表定义之间用 `---` 分隔

4. **同名表处理**：如果文档中有同名表（如中医/西医病案首页），按文档出现顺序分别记录，表清单中每个只出现一次

## 下游脚本依赖

以下脚本依赖此固定格式：
- `scripts/generate_export_sql.py` — 从"表清单"章节提取表名，生成导出SQL
- `scripts/compare_with_docx.py` — 从"字段定义"章节提取字段，与CSV对比
