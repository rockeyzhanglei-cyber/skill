# sun-angle — 太阳方位角与仰角计算

## 技能说明

计算指定地点、指定日期的太阳方位角和仰角，帮助判断某个朝向在一天中的采光情况。

## 触发条件

用户提到以下关键词时启用此技能：
- 计算阳光 / 太阳方位角 / 仰角 / 采光分析
- 日照分析 / 阳光角度 / 太阳高度角

## 使用方法

### 需要收集的参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--date` | 日期（YYYY-MM-DD） | `2026-04-30` |
| `--lat` | 纬度，北纬为正 | `36.06` |
| `--lon` | 经度，东经为正 | `103.83` |
| `--elev` | 海拔（米） | `1520` |
| `--facing` | 朝向偏北角（顺时针，度） | `45`（东北方向） |

**朝向说明（顺时针偏北）：**
- 正北 = 0°
- 正东 = 90°
- 正南 = 180°
- 正西 = 270°
- 东北 = 45°，西北 = 315°，东南 = 135°，西南 = 225°

### 执行命令

```bash
python3 ~/.cache/WinCode/skill/sun-angle/scripts/sun_angle.py \
  --date <日期> \
  --lat <纬度> \
  --lon <经度> \
  --elev <海拔> \
  --facing <朝向角>
```

### 输出说明

输出每天 06:00—18:00，每 30 分钟一个时间点，包含：
- **太阳方位角（绝对）**：以正北为 0°，顺时针增加（正东=90°，正南=180°，正西=270°）
- **相对方位角**：以用户朝向为基准，**正前方=90°，右侧=0°，左侧=180°，正后方=270°**
- **仰角**：太阳距地平线的角度（负值表示在地平线以下）
- **状态**：☀️ 可见 / 🌑 地平线以下

## 工作流程

1. 询问用户提供所有必要参数（日期、坐标、海拔、朝向）。
2. 如果用户只提供了地名，尝试推断大概坐标，或请用户确认。
3. 执行计算脚本并将结果直接展示给用户。
4. 如需要，可以解释结果含义（如上午某时段阳光直射正面等）。

用户："帮我算一下2026年4月30日，在兰州（北纬36.06°，东经103.83°，海拔1520米），面朝东北方向（45°），每半小时的阳光角度"

执行：
```bash

```
