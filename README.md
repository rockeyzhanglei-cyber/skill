# WinCode Skills

WinCode AI 技能集合，包含自动化开发、代码生成、项目管理等多种技能。

## 技能列表

| 技能 | 说明 |
|------|------|
| auto-dev | 全自动开发流水线 |
| backend-dev | 后端开发技能 |
| daily-report | 日报/周报生成 |
| data-model-compare | 数据模型对比 |
| data-model-revision | 数据模型修订 |
| find-skills | 技能查找 |
| frontend-dev | 前端开发技能 |
| git-merge | Git 合并操作 |
| java-unit-test-generator | Java 单元测试生成 |
| pm | 项目管理技能 |
| rdf-dev | RDF 开发技能 |
| reg-ddl-generator | DDL 生成器 |
| skill-creator | 技能创建/编辑工具 |
| sun-angle | 多角度分析 |
| tfs-pr-skill | TFS PR 操作 |
| ui-ux-pro-max | UI/UX 设计 |
| web-access | Web 访问技能 |
| win-skill-installer | 技能安装器 |

## 安装

将技能目录复制到 `~/.cache/WinCode/skill/` 即可使用。
