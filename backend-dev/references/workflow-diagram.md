# Backend-Dev Skill 流程图

> 最后更新: 2024-03-14

## 核心流程概览

```
┌─────────────────┐
│   需求获取       │ ← TFS工作项 / PRD文档 / 用户描述
│  (Step 0)       │   下载附件到 product-docs/
└────────┬────────┘
         ▼
┌─────────────────┐
│  读取项目上下文   │ ← CLAUDE.md + AKSO 规范
│  (Step 1)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│   进入 Plan 模式  │ ← 生成实施计划
│  (Step 2)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│   用户审核计划    │ ← 人工确认
│  (Step 3)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│  创建开发分支     │ ← feature/需求号-功能简述
│  (Step 4)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│    编码实现      │ ← Controller → Service → Repository
│  (Step 5)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│   运行测试验证    │ ← mvn test
│  (Step 6)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│   代码格式化     │ ← spotless:apply
│  (Step 7)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│  保存修改记录     │ ← /docs/feature/yyyy-mm-dd-需求号.md
│  (Step 8)       │
└────────┬────────┘
         ▼
┌─────────────────┐
│ 导出对话并上传TFS │ ← 上传附件 + 打标签 AI-CODING
│  (Step 9)       │
└─────────────────┘
```
