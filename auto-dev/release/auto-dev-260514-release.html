pipeline.yaml 配置驱动的流水线架构

全新的 pipeline.yaml 配置体系，让你的开发流程完全可定制。
每个阶段（需求分析 → 编码 → 校验 → 提交 → 构建 → 部署 → 报告）都可以自由组合、替换、跳过。

提供交互式配置向导 configure-pipeline.py，一条命令即可生成专属流水线。
内置模板 pipeline-template.yaml + 详细注释，5 分钟上手。

单元测试阶段正式集成 NEW

新增 stage-unit-test.md，单元测试作为独立阶段接入流水线。
支持 Java (JUnit5/TestNG)、Vue3 (Vitest/Jest)、Vue2 (Jest) 全技术栈。
可通过 pipeline.yaml 灵活启用/禁用，不影响现有流程。
